# 题解库

做过的题按平台存放，每个文件开头写清楚题目信息。和灵神的 `main/` 目录一样，题解既是练习记录，也是检验模板正确性的依据。

## 目录与命名

| 平台 | 路径示例 |
|---|---|
| Codeforces | `codeforces/1900-1999/1919D.cpp`（按比赛编号每 100 场一个目录） |
| AtCoder | `atcoder/abc340/E.cpp` |
| 洛谷 | `luogu/P3372.cpp` |
| LeetCode | `leetcode/3113.cpp`（题号） |
| 其他 | `others/比赛名/题号.cpp` |

## 文件开头的格式

```cpp
// https://codeforces.com/problemset/problem/1919/D   难度 2100
// 标签：单调栈、结论
// 思路：（一两句话，写出关键转化）
// 用到的模板：02_ds/01 单调栈
```

做完一道有价值的题后，记得把"链接 + 难度 + 一句话提示"补到对应模板文件的【题单】里。
